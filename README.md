# Vídeos motivacionales — almacenamiento temporal

Este repositorio público está reservado para archivos de vídeo que se hayan autorizado para publicación.

No contiene el código del generador, contraseñas ni claves de acceso.

**Estado:** preparado como destino público; la subida automática, la publicación en redes y la eliminación posterior aún están pendientes de verificación.

Los vídeos solo deben eliminarse tras confirmar su publicación en ambas plataformas y que el programador ya no necesita el archivo.
